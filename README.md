# Projectile Motion with Air Resistance

This repository contains Python simulations of projectile motion
under ideal conditions and with air resistance.

## Files
- ideal_projectile.py: Simulation without air resistance
- air_resistance.py: Simulation with air resistance
- comparison.py: Comparison of both cases

## Method
Numerical methods were used to simulate projectile trajectories.
The effect of air resistance on range and height was analyzed.

## Purpose
This project was developed for academic and research purposes.
